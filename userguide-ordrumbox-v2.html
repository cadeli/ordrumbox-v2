1. Getting Started

OrDrumbox v2 is a browser-based drum machine and pattern sequencer. Click Start on the waiting screen to open the application. On a desktop screen you then see:

  • Toolbar at the top — main controls
  • Pattern Panel — the step sequencer grid
  • Track Editor and Output Panel — open beside the grid

Basic Workflow

  1. Select a Pattern from the Pattern dropdown
  2. Click ▶ (or press Space) to start playback
  3. Click on the grid to add/remove notes
  4. Click a track name to show that track in the Track Editor
  5. Click a note to show it in the Note Editor
  6. Use ↻ Drum, ↻ Bass or ↻ Chords to generate parts
  7. Open the Song view to chain patterns into an arrangement

Editing a note's velocity & pitch

A note can be tuned straight from the grid, without opening the Note Editor. Two gestures do the job, and they work the same way in the Piano Roll.

Action Result
Drag a filled cell up / down Velocity (0–1), +0.005 per pixel — a full sweep is ~200 px
Drag a filled cell left / right Pitch, one semitone per 12 px
Shift + ↑ / ↓ (note picked with the mouse) Velocity ±0.05
Shift + ← / → (note picked with the mouse) Pitch ±1 semitone
  • Axis lock: the gesture commits to one axis after 3 px of movement, so a sloppy diagonal never changes both velocity and pitch at once.
  • Chords: in a cell holding several notes, the slice under the pointer is the note edited — one voice per slice.
  • Audible: the note is re-played as it changes (a few times per second at most), so an edit is never silent.
  • Safe: a drag never deletes the note — the click the browser sends at the end of the gesture is swallowed. A plain click still selects the note, and a second plain click still deletes it.
  • Undo: a whole drag (or a held key) is one history step — Ctrl/Cmd + Z restores the original value in one go.

Shift + Arrow has two meanings in the grid. It edits the note only when that note was picked with the mouse (a click or a drag); when the note was merely reached by walking the cursor with the arrows, Shift + Arrow keeps extending the multi-step selection used for a range delete. A plain arrow always hands Shift + Arrow back to range selection.

Editing gauge

While a velocity or pitch is being edited, a gauge pops up over the note:

  • a knob-style arc that fills with the value — velocity directly (0.8 fills 80 % of the sweep), and for pitch the place the note occupies on the keyboard, so the arc moves as you transpose;
  • the note name and its MIDI number, then the new value with a ▴ / ▾ arrow;
  • a coloured ring around the edited cell.

The gauge stays up while you drag or hold the key, then fades out about 700 ms after the last change. The note's own tooltip is hidden while the gauge is displayed, so the two never overlap, and comes back afterwards. The pattern grid has no pitch axis, so this gauge is the only place a transposed note can be read.

4. Track Editor

The Track Editor shows the track selected in the grid. At the top, the sample bar displays the sample's pitch, duration and peak with its waveform and decay marker, and ↑ replaces the sample with an audio file (WAV/FLAC/MP3/AAC). Below it come four knobs and five tabs: fx, sound, mod, loop and gen.

Track parameters are undoable; a whole knob drag is one undo step.

Knobs

Control Range Default Description
Vel 0–1 1 Track volume multiplier
Pan -1 to 1 0 Stereo panning (left/right)
Pitch -24 to 24 0 Pitch offset in semitones
Decay 20–5000 ms (log) sample default Fade-out time of the sample. It is stored with the sample, so it also shows in the Drumkit Manager and affects every track using that sample.

gen Tab

6. Tools Panel

The Tools Panel opens with the ⚙ button in the toolbar (desktop only). It has six tabs: Pattern, Export, Import, Status, MIDI and Cache.

Pattern Tab

Button Description
Compact Tracks Detects repeating note patterns across tracks and adds loop points to minimize the number of notes
Rnd Writes random notes into each track of the current pattern using the pattern generator

Export Tab

Button Format Description
Export MIDI .mid Exports as Standard MIDI File (SMF Type 1, multi-track)
Export WAV .wav Renders the selected pattern to audio
Export Song .wav Renders the selected arrangement (every clip, layered, at the song's tempo)
Control Range Default Description
Loops 1–32 1 Number of times pattern loops in WAV/MIDI export

Export MIDI and Export WAV apply to the selected pattern. Filenames: ordrumbox-{patternName}.{ext}. To save a pattern as JSON, use ↓ in the pattern header or Ctrl/Cmd + S.

Which tracks are exported: the same rule as playback — if at least one track is soloed, only the soloed tracks are exported, otherwise every track that is not muted.

MIDI Export details:

  • Standard MIDI File, Type 1, resolution 96 PPQN (1 engine tick = 3 MIDI ticks)
  • Track 0 (conductor): track name orDrumbox Pattern, 4/4 time signature and the tempo of the pattern
  • Track 1+: one MIDI track per exported track, named after the track (a track without notes is omitted)
  • Drum instruments → MIDI channel 10; melodic instruments get their own channel plus a Program Change
  • Base note = the instrument's GM key, otherwise C3 (48); melodic samples with a root note use it as base. Pitch = track pitch + note pitch (+ pitch LFO)
  • Velocity (0–127) is the note velocity × 127; a velocity LFO replaces it
  • Every note is written as a fixed 16th-note (24 MIDI ticks) note on/off pair
  • Not exported: pan, filter LFOs and other parameters without a MIDI equivalent
  • Loops repeats the pattern in the file (each loop offset by the pattern length)

WAV Export details:

  • Rendered offline (OfflineAudioContext) with the same engine and mixer as playback, including track effects
  • Format: 16-bit PCM, stereo, 44.1 kHz
  • Length = beats × 60 / BPM × loops (8 beats at 120 BPM = 4 s per loop)
  • The button label changes to Exporting... until the file download starts
  • The sounds of the exported tracks must be loaded — samples belonging to another drumkit are loaded on demand (see Track Editor → Sound)

Import Tab

Import MIDI opens a file picker for .mid / .midi files and imports the file into new patterns. A long file is split into patterns of 32 beats, up to 16 patterns.

JSON patterns are imported with ↑ in the pattern header; folders of samples with Import Directory in the Drumkit Manager.

Status Tab

Shows the state of Web MIDI with one LED per line: Support, Ready, Inputs, Ext Sync and Activity.

MIDI Tab

Control Description
Output MIDI output device
Enable MIDI Connects or disconnects MIDI (the browser may ask for permission)
Toggle Sync Switches between the internal clock and an external MIDI clock

Cache Tab

Lists what the application keeps in the browser (patterns, drumkits, samples, settings, songs, synth presets) with size and date. Each line can be removed with ✕; on desktop, all but samples can also be read as JSON.

Button Description
Refresh Reloads the list
Clear Patterns / Drumkits / Samples Empties that part of the cache
Factory Reset Clears all cached data at once, without confirmation. Export anything you want to keep first.

7. Output Panel

The Output Panel opens with the application on desktop, and when you click the Master row of the pattern grid or the Master tab on mobile. It has three tabs — vol, Comp and Flt — and a real-time spectrum analyzer. Its settings are not part of the undo history: to revert, move the control back.

Master

The vol tab holds the master output volume knob.

Control Range Default Description
Volume 0–2 1.0 Master output volume (rotary knob). Vertical drag or arrow keys to adjust.

Filters (Master)

The filters section is part of the master bus signal chain, applied after the compressor.

Control Range Default Description
Low Cut 10–500 Hz 35 Hz High-pass filter (removes low frequencies)
High Cut 1000–20000 Hz 18500 Hz Low-pass filter (removes high frequencies)

Compressor

The compressor section uses a VST-style rotary knob layout with a power button toggle. The signal chain is: Pre-Gain → Compressor → Low-cut → High-cut → Master Gain.

The power button (⚡ icon, top-right) bypasses the whole block: pre-gain, compressor and both filters. Green glow = active, dimmed = bypassed.

Control Range Default Unit Description
Pre-Gain -20 to +20 0 dB Input gain before the compressor (rotary knob, separated below the other knobs)
Threshold -40–0 -18 dB Compression threshold (rotary knob)
Ratio 1–20 8 — Compression ratio (rotary knob)
Attack 0–1 0.002 s Response speed (rotary knob)
Release 0–1 0.08 s Recovery speed (rotary knob)
Knee 0–40 3 dB Curve softness (rotary knob)
Makeup 0–24 8 dB Output gain to compensate for compression (rotary knob)

Knob interaction: Vertical drag to change value. Arrow keys move one step. Shift or Alt/Option + arrows for fine mode (×0.1), Ctrl/Cmd + arrows for large steps (×10). Shift+drag is fine mode too. Double-click to reset to default. Right-click opens a numeric input to type an exact value (clamped to min/max and snapped to step). The same applies to the sliders.

Spectrum Analyzer

A real-time frequency spectrum display updated via requestAnimationFrame. Beats are colored from dark (low amplitude) to red (high amplitude).

8. Synth Editor

The Synth Editor edits soft-synthesizer presets. Open it with the Synth view button (or the Synth tab on mobile). It shows the preset of the selected track, or the first preset if the track plays a sample. Parameters are arranged in four tabs: OSC, FLT, MOD and ENV.

Edits apply and save immediately, and they are not part of the undo history — use Revert to restore the preset.

subGain 0–1 0 Sub-oscillator level
pitchPunch 0–1 0 Amount of the pitch punch at the start of the note

Oscillators (VCO1, VCO2, VCO3)

Three independent oscillators with PolyBLEP anti-aliasing. Each oscillator has:

Parameter Range Default Description
gain 0–1 vco1:1, others:0 Oscillator volume
octave -4 to 4 0 Octave offset
detune -100 to 100 0 Fine detuning in cents
wave sine, triangle, sawtooth, square, random sine Waveform. random holds a new random value for each cycle.

FM (Frequency Modulation)

Parameter Range Default Description
amount 0–1 0 FM depth. When > 0, modulators affect carrier frequency. The modulation amount scales the modulator output by ×1000 Hz.
algo 0–4 0 FM routing algorithm (see below)

FM Algorithms:

Algo Routing Description
0 2 → 1 VCO2 modulates VCO1 frequency
1 3 → 1 VCO3 modulates VCO1 frequency
2 3 → 2 → 1 Serial chain: VCO3 modulates VCO2, VCO2 modulates VCO1
3 2+3 → 1 VCO2 and VCO3 both modulate VCO1 (parallel)
4 2 ↔ 1 Cross-modulation: VCO2 modulates VCO1 and VCO1 modulates VCO2

How FM works:

  • At amount = 0, oscillators run independently (standard subtractive mode).
  • At amount = 1, maximum frequency modulation is applied, creating complex sidebands.
  • Use the Algo selector to choose different modulation routings.

Filter

Parameter Range Default Description
type lowpass, highpass, bandpass lowpass Filter type (TPT SVF topology)
freq 20–20000 Hz 400 Hz Cutoff frequency
Q 0.1–24 1 Resonance (higher = narrower peak at cutoff)
drive 0–1 0 Filter drive
Env 0–1 0 Filter envelope modulation depth. When > 0, sweeps the cutoff frequency upward during the attack phase and back during the decay phase.

Filter envelope behavior: When Env > 0, the cutoff frequency sweeps from its base value toward 20 kHz during the attack time, then returns to the base value during the decay time. At Env = 1, the sweep reaches the full 20 kHz range.

9. Piano Roll

The Piano Roll is an alternative view to the Pattern Panel step grid. It displays notes on a vertical pitch axis (MIDI-style) with time on the horizontal axis. Open it with the proll view button (or the Piano tab on mobile). It edits the selected track.

Layout

  • Keys column (left): piano keyboard showing MIDI note names (C3, C#3, D3, etc.)
  • Grid: time flows left-to-right, pitch flows bottom-to-top
  • Notes: horizontal rectangles — length = duration, vertical position = pitch

Interactions

Action Result
Click on empty grid Creates a note at that pitch and time
Click on a note Selects it, opens Note Editor
Click on selected note Deletes it
Arrow keys Move cursor (pitch up/down, time left/right)
Drag a note up / down Velocity, +0.005 per pixel
Drag a note left / right Pitch, one semitone per 12 px (the note moves to the new row)
Shift + ↑ / ↓ (note selected) Velocity ±0.05 on the selected note
Shift + ← / → (note selected) Pitch ±1 semitone on the selected note
Enter Create or toggle note at cursor position
Delete / Backspace Delete the note at the cursor
Right-click grid Note menu: Add note, Delete note, Add minor chord, Add major chord (chord uses the clicked pitch as root)
Right-click keyboard Keys menu: Clear all (wipes track notes), Add sequence (replaces notes with one chord per 4-beat measure from the standard progression library — clicked key is the tonic; sequences cycle on each use)

Editing velocity & pitch: dragging a note and Shift + Arrow on the selected note edit its velocity (up/down) and pitch (left/right), with the same editing gauge as the pattern grid: arc, note name, new value, and a ring on the note. The note is previewed while it changes, a drag never deletes it, and the whole gesture undoes as one step. The pitch is kept inside the visible keyboard (MIDI 12–108, shifted by the track pitch), so a note can never be transposed off the grid.

Page navigation: The piano roll displays one page (4 beats) at a time. Use the ◀ / ▶ buttons of the panel or the toolbar, or Shift + mouse wheel.

10. Song Panel

The Song Panel holds the pattern list and chains patterns into an arrangement. Open it with the Song view button. While this view is shown, playback runs the whole arrangement at the song's tempo.

Pattern List

  • Click a pattern to select it
  • Double-click a pattern name to rename it
  • Right-click a pattern to add it to the arrangement at the current measure

Patterns are created and deleted with the buttons of the pattern header (see Pattern Panel).

Arrangement

Time runs left to right, one cell per measure. Each pattern used has its own row, and each clip is a rectangle over the measures it plays. A cursor shows the position.

Action Result
Click a measure number Moves the cursor there; the next play starts from that measure
Right-click an empty cell Add here: adds the pattern of that row at that measure
Right-click a clip Next repeats the pattern right after the clip; Delete removes the clip
Right-click a pattern name Add at measure N adds a clip at the cursor; Delete row removes every clip of that pattern

Clips are placed from these menus; they cannot be dragged. Render an arrangement with Export Song in the Tools Panel.

Song Actions

Control Description
Song Double-click the name to rename the song (default: "Untitled")
Description Free text, edited in place
Arrangement Chooses the arrangement shown in the grid
Save / Load Saves the song in the browser (IndexedDB), or loads one saved there
Export / Import Saves the song to an .odbox file, or loads a .odbox or .json file

15. Audio Signal Flow

Per-Track Signal Chain

Sample/Synth → Filter → Saturation → Dry Gain → Reverb → Delay → Stereo Panner → Mixer Bus

Master Bus Signal Chain

Mixer Bus → Pre-Gain → Compressor → Low-cut Filter (35 Hz) → High-cut Filter (18.5 kHz) → Master Gain → Analyser → Speakers

All tracks feed into a shared mixer bus. The master bus applies pre-gain, then compression, then filters and final gain before reaching the output.
